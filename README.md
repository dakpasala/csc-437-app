For some reason, the app sometimes doesn't work on a chrome profile. I think it's because of chrome extensions of mine, but if data doesn't load, please try using it on incognito.

To actually see multiple pages, you can click on the bolded opposition team to see their speciifc pages.
When you click another team, the CSS automatically adjusts to the team's light and dark colors. (One of my favorite features)
The dark mode also persists across all pages and you can see how the darker color becomes the viewing point.

In edit mode, you can change the team's coach, conference (this will never really be edited, but with the expansion of the NBA, teams can go from one conference to another), players, games, and championships.
I had to start to add NFL teams as oppositions because the Lakers page already had the 29 other teams.
